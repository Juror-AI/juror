# Greptile landing-page sitemap

Captured from Greptile's public XML sitemap on 2026-09-21. The full crawl contained 632 URLs: 472 generated `grepository` pages, 51 documentation pages, 29 blog posts, 19 job pages, 9 customer stories, 15 content-library articles, and 37 top-level or report URLs. Generated directories, posts, and jobs are deliberately excluded from this competitive landing-page inventory.

## Content strategy decision

Juror should compete where the product has proof: open-source ownership, direct provider billing, multi-model review, transparent receipts, reproducible benchmarks, GitHub Actions, and a local CLI. It should not invent customer, self-hosting, SSO, security-review, or enterprise claims merely to match a competitor's URL count.
